The fixed scope is canonical metadata/annotation selection and existing plain-Type/Definition general-type consumers. The current full trace records 185,055 ms of completed general-type exclusive time versus 2,313 ms in completed redefinition-closure evaluation. This diagnostic includes uninstrumented calls and tracing overhead; it is not a comparable Pilot benchmark.
